## Local code and build changes

- Standalone CMake project and WinLibs presets; build all three programs,
  compile help/messages, preserve runtime data beside the executables, install
  documentation and source license notices, and register the serial tests.
- PowerShell test runner with per-process timeout, isolated initialization and
  history, exact output checks, invocation logs, hashes, and G: media cleanup.
- Correct `ssdef.h`'s mismatched guard and the same typo in the Perl generator
  template. Retain the checked-in message tables instead of regenerating them
  through an unqualified Perl workflow.
- Fix Windows DWORD and VHD diagnostic formats, signed comparisons, explicit
  character lookup tables and calloc argument order. Scope MSVC pragmas to
  MSVC. Retain useful warnings rather than suppressing them globally.
- Return the actual VHD seek error instead of unrelated `errno`, which could
  be zero and allow use of an uninitialized footer offset. Compare UTF-16 BOM
  bytes as unsigned bytes; this is not a claim of full Unicode path support.
- Finish an opened `@command-file` before consuming later command-line
  commands, so a following `exit` cannot silently skip the file.
- Invoke VHD snapshot creation once. Strip virtual aliases from host creation
  and failure-cleanup paths, while retaining aliases for the subsequent mount.
- Let RMS supply STREAM/STREAMCR delimiters instead of retaining an extra host
  LF; write explicitly generated CRLF in binary host mode to avoid CRCRLF.
- Supply the missing precision argument in the wrong-volume diagnostic;
  before the fix the expected label printed arbitrary bytes.
- Show the GCC version on MinGW-w64 instead of describing the MinGW header
  package version as the compiler version.

Nine failed development case receipts remain in the evidence. They include
the command-file/snapshot/text/diagnostic defects and corrected test assumptions
about auto-assigned device letters, initialization files, and diagnostic words.
They are not counted as passing final tests. Cleanup was checked on failures.
An ordinary Git whitespace check treated the repository's existing CRLF line
endings as trailing whitespace; a command-local CRLF-aware check passed while
preserving the original file endings.
